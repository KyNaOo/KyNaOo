### 🚀 Projet phare : Deskflow

> Help desk SaaS **multi-tenant** : chaque organisation reçoit les demandes de ses clients via un portail, et ses agents les traitent **en temps réel**.

- ⚡ **Temps réel multi-instances** : Socket.io + adapter Redis, indicateur « en train d'écrire », mises à jour optimistes
- 🔒 **Isolation multi-tenant automatique** au niveau de Prisma, JWT + refresh tokens avec détection de vol
- 📨 **Worker asynchrone** (BullMQ) : e-mails avec retries, tâches planifiées, nettoyage du stockage
- 📊 **Analytics** calculées en SQL (médianes, séries temporelles), tableau de bord accessible WCAG 2.1 AA
- 🐳 **Entièrement dockerisé**, CI GitHub Actions, images de prod multi-stage, démo déployée derrière Caddy (HTTPS)

`TypeScript` `NestJS` `Next.js` `PostgreSQL` `Redis` `BullMQ` `Socket.io` `Docker` `Turborepo`
